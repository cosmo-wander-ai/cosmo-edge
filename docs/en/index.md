## Reading Path

1. First-time users should start with [Volume 1: Quick Start](tutorials/01-quickstart/quickstart.md).
2. To confirm build commands, read the [Build Guide](guide/build.md).
3. To understand runtime paths, ports, and services, read the [Deployment Guide](guide/deployment.md).
4. To understand the project layout, read the [Architecture Overview](guide/architecture.md).
5. To troubleshoot runtime issues, read [Troubleshooting](guide/troubleshooting.md).
6. For integrations, read [API Overview](reference/api.md), [API Fields](reference/api-fields.md), [MQTT Reference](reference/mqtt.md), [HTTP Webhook Reference](reference/webhook.md), and [Models and Resources](reference/models.md).
7. For development, read [Frontend Development](development/frontend.md), [Backend Development](development/backend.md), and [CI and Quality Checks](development/ci.md).
8. Before publishing the repository, read the [Open Source Checklist](project/open-source-checklist.md), [Sensitive Data Review](project/sensitive-data-review.md), [Security Notes](project/security.md), [Third-Party Licenses](project/third-party-licenses.md), [Release Notes](project/release-notes.md), [Repository Metadata](project/repository-metadata.md), [Public Validation Report](project/validation.md), and [Benchmark Reproduction Guide](project/benchmarks.md).
