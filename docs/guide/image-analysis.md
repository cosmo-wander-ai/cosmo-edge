# 图片分析与图片比对

图片分析按照场景中的模型、筛选、判断和结果输出节点执行。先选择场景，再上传图片；返回值包含编排后的业务结论。接口集成见[图片检测 API 接入指南](../reference/image-detection-api.md)。

## 选择场景

在 **场景任务** 页使用 **数据源类型** 查询条件，选择 **图片分析**，即可查看图片类场景；选择 **视频分析** 查看视频类，选择全部则清除类型限制。图片分析页的算法下拉框只列出图片类场景。

| 需求 | 选择方式 | 输入与结果 |
| --- | --- | --- |
| 检测、分类、OCR 或 VLM 判断 | 对应图片场景 | 一张图片的目标、文字或业务结论；页面可批量提交多张图片，各自独立分析 |
| 与已登记样本比对 | 图片人脸比对、图片未穿工服 | 一张图片与所选底库比对，返回业务结论和命中样本信息 |
| 比较两张图片 | 双图人脸比对、双图工服比对 | 图片 A 与图片 B，返回一个 0–100 的相似度分数 |

新建场景时将数据源类型设为 **图片分析**。确认卡片上的模型状态正常，再进入 **算法编排**。图片任务没有检测区域或屏蔽区域，也没有视频跟踪、持续时间、绊线或离岗语义。目标裁剪使用检测框，不需要绘制区域。

## 使用单图与底库比对

1. 对于底库比对，先在对应的人脸库或工服库中创建分组并登记有效样本。底库中的图片必须有可用的特征；仅看到图片缩略图不能证明该样本可参与比对。
2. 打开 **图片分析**，选择 **图片人脸比对** 或 **图片未穿工服**，展开 **分析参数**。
3. 从 **绑定人脸分组** 或 **绑定工服分组** 下拉框选择分组，可以选择多个。工服场景只需绑定工服库；人脸场景只需绑定人脸库。
4. 检查检测置信度、最小目标尺寸和场景暴露的比对阈值，再上传图片并点击 **开始分析**。
5. 查看每张图片的业务结论。命中底库时，页面同时展示样本名称、所属底库、底库图片和比对分数；点击底库图片可预览。

库选择器也用于场景参数配置和 **图片库比对** 组件的配置面板。组件的 **比对库类型** 决定显示哪一种库，**判断方式** 决定业务规则接受“命中”还是“未命中”。保存场景修改后，重新选择场景以加载最新参数；图片分析页的参数只覆盖本次分析，不会保存为场景默认值。

### 业务命中与底库命中

“命中”指当前场景的业务规则成立。以 **图片未穿工服** 为例：

| 比对证据 | 底库结果 | 未穿工服业务结论 |
| --- | --- | --- |
| 有有效样本参与比对，找到满足阈值的工服样本 | 底库命中 | 未命中：没有触发“未穿工服”规则；仍展示底库图片和分数 |
| 有有效样本参与比对，最高分未达到命中条件 | 底库未命中 | 命中：触发“未穿工服”规则 |
| 没有可参与比对的有效样本 | 证据不足 | 无法判断；不能据此认定未穿工服 |

卡片标题后的 `(0)` 是业务命中目标数，不是相似度分数。接口中的业务结论位于 `outputs[]`，底库命中信息位于 `targetList[].matchInfo`。相似度和检测置信度是不同指标。

### 排查“无法判断”与执行失败

| 提示 | 含义与处理 |
| --- | --- |
| 没有设置人脸底库 / 没有设置工服底库 | 未选择对应分组，属于配置错误；先选择底库再分析 |
| 无法判断：没有可参与比对的有效底库样本 | 已提供库绑定，但有效比对样本数为零。检查分组仍存在、样本特征非空且与当前特征模型兼容、模型比对配置有效 |
| 无法判断：缺少有效判断依据 | 当前规则缺少所需输入。开启调试详情后重新分析，检查上游节点输出、筛选原因和规则输入 |
| 未命中 | 业务规则未成立；结合具体场景理解，不代表程序异常 |
| 分析失败，附具体错误 | 模型加载、输入解码、特征或节点执行失败；按错误信息定位，不应当作未命中 |

使用库里的原图仍无法判断时，先查样本特征是否有效、登记与分析是否使用兼容的特征模型。降低阈值不能修复没有有效样本的问题。修复模型或特征提取问题后，应重新登记受影响样本。

**调试详情** 开关对下一次分析生效，可查看节点耗时、输入/输出数量、跳过状态以及被筛除的目标。诊断时先检查是否检测到目标，再检查筛选、特征和库比对；API 调用方还可读取 `outputs[].reason` 和 `matchInfo.setPicCount`。

## 使用双图比对

1. 选择 **双图人脸比对**（内置 ID `93000002`）或 **双图工服比对**（`93000058`）。
2. 分别在图片 A、图片 B 的上传位置选择图片；两侧都提供后才能开始分析。
3. 每张图片须恰有一个通过检测和筛选的有效目标。人脸比对使用人脸目标，工服比对使用人体目标。
4. **比对阈值** 留空时只返回分数；填写 0–100 的阈值时，分数大于等于阈值显示命中，否则显示未命中。清空阈值可恢复只输出分数。
5. 点击 **开始分析**，查看两侧图片、检测目标裁剪和分数。更换图片或参数后可重新分析。

双图比对无需创建或绑定底库。两张图片通过相同模型和参数分别提取特征，再执行一次比对。低于阈值仍会返回实际分数，有效的 0 分也会显示。

没有有效目标、存在多个有效目标、特征无效或图片解码失败时，显示具体错误及出错侧，不会给出一个成功分数。当前双图编排只支持一条检测到特征提取的处理链、一个 **双图特征比对** 节点和一个 **图片结果输出** 节点，不支持分支、合流或多目标两两匹配。

分数表示模型标定后的相似程度。工服比对复用人体外观特征，受人体姿态、背景和图像质量等输入差异影响；分数不代表身份概率或“穿同款工服”的概率。

## 调整图片编排

常用处理顺序：

| 场景 | 节点顺序 |
| --- | --- |
| 检测后判断 | 图片检测 → 图片目标筛选 → 可选分类 → 图片目标判断 → 图片结果输出 |
| 人脸底库比对 | 人脸检测 → 筛选 → 关键点 → 人脸特征提取 → 图片库比对 → 图片结果输出 |
| 工服底库比对 | 人体检测 → 筛选 → 可选质量分类/筛选 → 人体特征提取 → 图片库比对 → 图片结果输出 |
| 双图比对 | 对应的检测/筛选/特征链 → 双图特征比对 → 图片结果输出 |

**图片结果输出** 的 **结果名称** 用于命名业务结论，**返回目标** 可选命中目标或全部通过筛选的目标。单图业务响应可能额外携带命中底库的目标证据，因此业务方应以输出节点关联的目标为准。图片结果输出不会自动创建视频事件或触发外部推送。

整图判断、条件分支、整图/目标分类、OCR、DINO、SAM 和 VLM 可按组件输入要求组合。单图编排支持分叉，不支持合流；双图编排使用上一节的单链约束。条件分支只有命中才执行下游；无法判断不会被取反为命中。

## 内置模板与场景任务

目前 BM1688、CV186X 和 x86 的资源目录均包含 13 个从视频转换的图片模板，并各提供一份同 ID 的内置场景：

| ID | 图片场景 |
| --- | --- |
| `92000002` | 图片人脸比对 |
| `92000006` | 图片人员跌倒 |
| `92000009` | 图片烟雾检测 |
| `92000010` | 图片火焰检测 |
| `92000011` | 图片吸烟检测 |
| `92000012` | 图片打电话检测 |
| `92000015` | 图片未戴安全帽 |
| `92000022` | 图片玩手机检测 |
| `92000029` | 图片车牌识别 |
| `92000032` | 图片未穿反光衣 |
| `92000058` | 图片未穿工服 |
| `92000065` | 图片睡岗检测 |
| `92034707` | 图片视觉语言大模型分析 |

另提供 `93000002`、`93000058` 两个双图模板和场景。转换保留原视频模板，仅表达单张图片可以判断的状态；需要区域、绊线、离岗、持续时间或历史计数的模板不会直接转换。

这些是随资源包提供的配置，所需模型仍须适配实际芯片并安装。升级后的场景列表以设备实际加载结果为准；旧的自定义场景需要检查其节点和参数配置。模板生成和检查方法见 [API 指南中的模板说明](../reference/image-detection-api.md#从视频模板生成图片模板)。
