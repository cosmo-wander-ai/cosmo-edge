# ONVIF 视频接入

ONVIF 接入用于发现摄像机、获取视频 Profile 和取得 RTSP 地址；视频继续使用现有拉流、解码、预览、截图与场景任务链路。当前实现不包含 PTZ、音频、事件订阅或录像检索，也不代表 ONVIF 认证声明。

## 接入步骤

1. 在摄像机上开启 ONVIF，创建具有视频访问权限的 ONVIF 用户。部分设备的 ONVIF 用户独立于网页管理用户。
2. 在「视频输入」添加视频源，选择 ONVIF，然后选择「手动添加」或「自动发现」页签。独立 RTSP 账号默认不勾选，勾选后才显示对应账号和密码。
3. 手动添加：填写通道名称、摄像机 IP 地址、ONVIF 用户名和密码，点击「添加通道」。平台自动查询码流并保存，查询失败直接显示错误，不创建通道。地址也支持端口或完整 Device Service 路径。
4. 自动发现：搜索前只显示搜索操作，不显示账号输入框。点击「搜索设备」后，平台自动搜索边缘设备所有可用网卡，获取设备地址并生成通道名称。列表显示通道名称、只读 IP 地址、ONVIF 用户名和密码；每台设备账号独立，预填 `admin / admin`，这只是输入默认值，不代表设备的实际账号。密码默认遮挡，请核对并修改后勾选需要的设备，点击「添加所选设备」。需要独立 RTSP 账号时展开对应行设置，默认不开启。搜索及输入账号过程中均不会发送认证请求；仅添加时自动查询码流并保存。发现由边缘设备执行，不依赖浏览器所在网段；跨网段无法组播发现时请手动添加。
5. 在原有视频列表中预览、截图或分配场景任务。保存成功仅表示配置已保存，实际在线状态以取流结果为准。

新通道自动选择具有有效分辨率、编码为 H264/H265/MJPEG 的 Profile，优先分辨率最高，其次帧率最高，两者相同优先 H264；不按名称猜测主、子码流，也不修改摄像机编码配置。编辑已有通道时优先保留原 Profile。界面不再提供手动选择 Profile，但底层 API 仍支持指定 Profile。

同一服务地址和 Profile 的重复保存会被拒绝。列表不展示码流和结果列；添加失败时在对应通道名称下方提示原因，某台失败不影响其他设备。修改该行账号后再次添加即可重试，重新搜索不会覆盖已修改的名称和账号，已经成功的行不会重复添加。添加成功或关闭弹窗后清除相应行的内存密码，不在浏览器持久保存。取消仅停止尚未开始的操作，正在执行的请求会完成或超时；若保存请求已经发出，其成功结果仍会保留。

## 维护与排查

- 编辑视频源可更换名称、地址和凭据；密码留空保留原值，保存时自动重新查询码流，已有拉流会重新解析地址。
- 认证失败先检查 ONVIF 独立用户、权限和设备时间。平台只计算请求的时间偏移，不修改摄像机时间。
- 查询 Profile 成功但无法播放时，检查 RTSP 权限、端口、独立凭据和编码支持。ONVIF 认证成功不等于 RTSP 认证成功。
- 自动发现无结果时，检查边缘设备网卡、UDP 3702 和组播网络，或改用手动地址。
- 服务请求有超时及并发上限，失败重试会退避。网络恢复或凭据编辑后重新取流，不需要重建场景任务。
- 比较延迟时应使用同一 Profile、编码、帧率、GOP 和播放器。ONVIF 取得地址后仍走 RTSP，不额外增加视频转码链路。

配置保存逻辑 `onvif://` 标识，不保存带密码的 RTSP URL。凭据加密存于运行配置目录下的 `onvif/`，该目录及密钥应一起备份；缺失密钥时不会覆盖旧配置。加密不替代设备访问控制，平台管理连接也应使用受信网络或 HTTPS。

## 实现边界

支持 IPv4 按网卡发现、手动地址、SOAP UsernameToken PasswordDigest 与 HTTP Digest、Media2 查询及 Media1 回退。HTTPS 校验证书，不自动信任自签名证书。设备返回的 SOAP 服务地址不得跨到另一主机。不同厂商的兼容性需要实机验证，不能由单一设备测试推断全部支持。

自动发现以响应报文的实际来源 IPv4 地址作为连接目标，保留有效广播服务地址的协议、端口和路径，避免错误主机名或仅有 IPv6 地址导致无法接入。没有有效广播服务地址时尝试默认 `/onvif/device_service` 路径；查询仍失败时显示错误，可改用手动地址。HTTPS 证书校验不会因此关闭。

现有视频输入 API 及任务配置继续复用；新增的认证 API 位于 `/gtw/cwai/Camera/OnvifInterfaces`、`OnvifDiscover`、`OnvifProbe`、`OnvifGet` 和 `OnvifSave`。调用方应检查 `resData.success` 和机器可读 `resData.error`，不得记录带凭据的请求体。
